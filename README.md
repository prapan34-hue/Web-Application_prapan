# DengueWatch

เว็บแอประบบเตือนภัยไข้เลือดออกล่วงหน้าด้วย Machine Learning

- Dashboard ความเสี่ยงระดับพื้นที่
- เปรียบเทียบ Logistic Regression, Random Forest, XGBoost และ LightGBM
- อธิบายปัจจัยด้วย SHAP
- สถาปัตยกรรม Data Sources → ML → Dashboard → Alert
